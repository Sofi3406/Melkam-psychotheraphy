### Appointment & Availability Constraints

- **Therapist Availability**
  - Each therapist cannot have overlapping `AvailabilitySlot`s.  
    → Enforced with `@@unique([therapistId, startsAt, endsAt])`.

- **Indexes added in Prisma schema**
  - `@@index([therapistId, startsAt])` on **Appointment** → speeds up therapist schedule lookups.
  - `@@index([patientId, startsAt])` on **Appointment** → speeds up patient appointment history queries.
  - `@@index([therapistId, startsAt])` on **AvailabilitySlot** → speeds up therapist availability lookups.

- **Example SQL indexes generated by Prisma**
  ```sql
  CREATE INDEX "Appointment_therapistId_startsAt_idx"
    ON "Appointment"("therapistId", "startsAt");

  CREATE INDEX "Appointment_patientId_startsAt_idx"
    ON "Appointment"("patientId", "startsAt");

  CREATE INDEX "AvailabilitySlot_therapistId_startsAt_idx"
    ON "AvailabilitySlot"("therapistId", "startsAt");
